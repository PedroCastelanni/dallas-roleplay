Base desenvolvida para **SA-MP (San Andreas Multiplayer)**, com seu desenvolvimento iniciado em meados de **2022**.

O projeto recebeu diversas atualizações, correções e novos sistemas ao longo do tempo. Posteriormente, seu desenvolvimento foi encerrado e a base acabou sendo abandonada.

Atualmente, este repositório é mantido apenas como **material de estudo e referência para a linguagem Pawn**.

## Finalidade

Esta base está sendo disponibilizada exclusivamente para fins **educacionais**.

O objetivo é permitir que outros desenvolvedores possam estudar estruturas, sistemas, lógicas e diferentes implementações utilizadas no desenvolvimento de servidores SA-MP com Pawn.

**Não é permitido utilizar este projeto para fins comerciais**, incluindo venda, revenda ou distribuição comercial da base, integralmente ou de forma modificada.

## Créditos

Nem todo o código presente neste repositório foi desenvolvido exclusivamente por mim.

Durante a existência do projeto, alguns sistemas e trechos de código foram desenvolvidos por **outros desenvolvedores**, além de códigos que foram adaptados ou modificados ao longo dos anos.

Por se tratar de um projeto antigo, iniciado em 2022, pode não ser possível identificar com precisão a autoria original de todos os trechos.

Caso reconheça algum código de sua autoria e os devidos créditos não estejam presentes, entre em contato para que a atribuição seja adicionada corretamente.

## Estado do projeto

> **Projeto descontinuado e sem manutenção.**

A base é disponibilizada no estado em que foi deixada e pode conter sistemas incompletos, bugs, códigos antigos ou dependências desatualizadas.

Não há garantia de funcionamento, atualizações futuras ou suporte técnico.

Este código é disponibilizado **somente para estudo da linguagem Pawn**.

Você pode analisar, estudar e utilizar trechos como referência para aprendizado, respeitando os respectivos autores e créditos.

**O uso comercial deste projeto não é autorizado.**
